Materi

1. Pengenalan Microsoft Excel

Excel adalah aplikasi spreadsheet untuk mengolah data berupa angka dan teks. Contohnya: daftar nilai, catatan uang jajan, dan jadwal piket.

2. Workbook dan Worksheet

Workbook adalah satu file Excel (.xlsx). Worksheet adalah lembar kerja di dalamnya (Sheet1, Sheet2, dst.). Analogi: workbook = buku, worksheet = halaman.

3. Row, Column, Cell, dan Range

  • Row (baris) bernomor: 1, 2, 3...
  • Column (kolom) berhuruf: A, B, C...
  • Cell adalah pertemuan kolom dan baris, misalnya B3.
  • Range adalah kumpulan cell, misalnya B2:B6.

4. Memasukkan dan Mengedit Data

  • Klik cell, ketik data, tekan Enter.
  • Tekan F2 atau klik dua kali untuk mengedit.
  • Tekan Delete untuk menghapus isi cell.
  • Teks rata kiri, angka rata kanan.

5. Operator Matematika Sederhana

Rumus selalu diawali tanda =.

OperatorArtiContoh
+tambah=B2+C2
-kurang=D2-B2
*kali=B2*2
/bagi=(B2+C2)/2
^pangkat=B2^2

Rumus Excel

Data contoh: nilai tugas lima siswa di B2:B6. Klik semua tab rumus.

Simulasi dan Praktik

Klik cell mana saja lalu ketik rumus, contoh =SUM(B2:B6) di B8. Tekan Enter.

=SUM(B2:B6)=AVERAGE(C2:C6)=MAX(D2:D6)=MIN(D2:D6)=COUNT(B2:B6)=(B2+C2+D2)/3
Hasil rumus akan tampil langsung di cell.
